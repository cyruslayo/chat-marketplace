    How this maps to the design

    • The agent at the bottom left is the presence dock: it pops up while the agent is thinking, working or replying, and its chip says what it is doing.
    • Swiping the strip only previews an agent. A task starts when you send a message or tap a starter (platform.task.start).
    • Each agent keeps its own chat. Switching swaps the visible chat; only your own words cross on an automatic switch.
    • Every loop stops within 5 seconds, every state has a still form, and a team member taking over silences the agent.
