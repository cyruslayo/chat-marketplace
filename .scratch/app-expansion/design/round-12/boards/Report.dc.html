Focus order

  1. Title on arrival
  2. Close Report a problem, Help
  3. What is wrong? (one Tab stop, arrows move)
  4. When did it start?
  5. What happened?
  6. Send report

Report sent: focus goes to the heading, then Back, Help, Reply (when a person has answered), the tab bar. No Ask bar, because a person owns it (ADR 0076).

Components

  • Task bar, Panel (commit edge), Facts list
  • Labelled field (choice group, text, textarea)
  • Banner (danger, neutral), Button, Action bar
  • Sent: App bar, Tab bar, Outcome, Steps, Chat message (human mark at 24px)

The safety panel uses the ink edge. Danger is kept for declines and failures, as the token says.
