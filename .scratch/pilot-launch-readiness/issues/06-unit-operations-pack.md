# Unit operations pack

Status: ready-for-human

## Acceptance criteria

- [ ] Each unit has a named on-site contact (caretaker or manager) with two tested phone routes (ADR 0067).
- [ ] Each unit has a check-in checklist: power and diesel, water, AC, Wi-Fi, cleaning done, security guard informed.
- [ ] Each neighbourhood has at least one backup unit for relocation (ADR 0028).
- [ ] Cleaning between stays is assigned to a named person for each unit.
