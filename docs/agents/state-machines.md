# State machines: map for agents

Read this before changing any `status`, `stage` or `state` field, or before adding a lifecycle.
Find code by symbol name; line numbers drift.

How to read the tables:

- **States** are the persisted or derived literals, quoted. Stored status strings are never renamed (PRD rule), so glossary drift is noted in the gaps column.
- **Type location** is the exported type or function that names the states. "inline" means the union is written in the record type and not exported.
- **Guard style** is one of: allow-list, deny-list, version CAS (compare-and-swap on a version number), SQL CAS, pure projection, or none.
- **Lazy-expiry rule** is where an expiry is evaluated against the clock on read, since nothing moves a row to `expired` in the background.
- **Gaps** link the tracking issue under `.scratch/state-machines/` (`map.md` lists issues 03 to 24). Owner questions are in `.scratch/state-machines/PRD.md`.
- A value that appears in a type but has no write site is a **never-written** state.

Exported lifecycle names listed below are checked by `test/state-machine-inventory.test.ts`. Adding a lifecycle without a row fails that test.

## Keeping this file current

Before changing any `status`, `stage` or `state` field, or adding a lifecycle, update this file's row in the same commit. `test/state-machine-inventory.test.ts` fails when an exported lifecycle name is missing here, or when a name here no longer exists in the scanned folders.
