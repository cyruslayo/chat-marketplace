# Project canonical interaction artifacts across channels

Authoritative application projections produce a canonical, versioned interaction artifact containing domain references, disclosures, policy versions, facts, amounts, absolute WAT deadlines, available actions, acknowledgements and sensitivity. Channel adapters render this artifact without recalculating or changing prices, deadlines, eligibility, rights, obligations or consent meaning.

Web may use A2UI and conventional pages. WhatsApp uses approved structured content or redirects complex, sensitive or insufficiently authenticated actions to the web. Instagram remains discovery and secure-link referral only. Every action passes a channel-capability matrix for meaning, disclosure, consent, authentication and audit; failure of any condition makes it unavailable in-channel. Channel switching preserves lawful context but reauthorizes sensitive content.
