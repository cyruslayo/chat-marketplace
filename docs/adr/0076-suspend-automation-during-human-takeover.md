# Suspend automation during human takeover

Interaction control moves explicitly among automated, handoff-requested, human-owned and resume-pending modes. Stopping a run ends generation, prevents new tools and attempts to cancel cancellable work, but does not reverse an already committed domain command or provider operation. The user receives the current committed state.

Safety, access, material remedy, exceptional financial, identity, misconduct, security, repeated-understanding and user-requested escalations require human ownership. During takeover the agent may assist staff privately but cannot message the user autonomously or submit state-changing commands. Context transfer is minimized and excludes reasoning and secrets. Automation resumes only after explicit human handback, a fresh projection and notice to the user; a suspended run is never silently restarted.
