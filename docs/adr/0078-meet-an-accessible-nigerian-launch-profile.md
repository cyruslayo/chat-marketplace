# Meet an accessible Nigerian launch profile

Launch web surfaces target WCAG 2.2 AA and support keyboard operation, screen readers, stable focus, understandable errors, contrast and reflow, reduced motion, practical 44-by-44 CSS-pixel targets, a 320-pixel viewport and degraded Nigerian mobile networks. Dynamic and streaming surfaces announce meaningful changes rather than tokens, preserve inputs on expiry and show absolute deadlines as well as countdowns.

Launch uses English (Nigeria), `en-NG`, NGN stored in kobo, and `Africa/Lagos` displayed as WAT. Contractual dates and money are unambiguous; relative time never replaces an absolute deadline. Text and critical facts load before nonessential media, material actions disable without current authorization and state, and all content is externalized for later localization. Rich UI is optional; comprehension of rights, amounts, deadlines and actions is not.
