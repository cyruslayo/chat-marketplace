# Retain deterministic parity for critical workflows

Agents may assist with explanation, discovery, comparison, draft preparation, guidance, status, triage, evidence intake, replacement search and handoff. Every state-changing or recovery-critical guest, operator and support workflow also has a conventional deterministic route using the same command type, schema, authorization, policy, concurrency and audit behaviour. There is no agent-only contractual or financial state transition.

At launch the agent cannot itself accept terms, confirm or cancel bookings, move money, approve exceptional remedies, make final risk, identity, safety or enforcement decisions, change prices or deadlines, disclose protected access data outside policy, perform arbitrary browser automation or generate executable code. If the runtime or CopilotKit fails, conventional search, contracting, payment, booking management, incident reporting and human support remain usable without loss of domain state.
