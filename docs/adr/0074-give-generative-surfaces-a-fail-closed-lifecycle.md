# Give generative surfaces a fail-closed lifecycle

Every A2UI surface has a durable identity, immutable catalogue selection, monotonically increasing revision, domain-version references, validity and an explicit lifecycle from creation through active, superseded, stale, expired, deleted or fallback states. Changes in aggregate version, deadline, authorization, quote, policy, inventory or human ownership immediately remove material action authority; stale submissions return a conflict and request a fresh projection.

Unsupported, invalid, expired or stale rich UI never guesses or silently omits required meaning. It retains the last safe non-actionable view where useful, provides complete text and a conventional route, preserves authoritative workflow state, and restores from server projections rather than browser storage. Deleting a surface neither erases its audit record nor reverses committed actions.
